# FitCoach — web sürümü

Antrenman ve beslenme programı hazırlama uygulamasının web sürümü.
Bu depo yalnızca **derlenmiş çıktıyı** barındırır; GitHub Pages üzerinden
yayınlanır.

**Adres:** https://emreyildiz19.github.io/fitcoach/

Telefonda Safari ile açıp **Paylaş → Ana Ekrana Ekle** dendiğinde ikonuyla,
tam ekran, uygulama gibi açılır.

## Veriler nerede duruyor?

Tamamı cihazın kendi tarayıcı deposunda. Sunucuya hiçbir şey gönderilmiyor,
bu depoda kişisel veri yok. Bunun iki sonucu var:

- Her telefon kendi verisini tutar; iki cihaz arasında senkronizasyon yoktur.
- Tarayıcı verileri temizlenirse kayıtlar silinir. Yedek için programın
  PDF çıktısını almak yeterli.
